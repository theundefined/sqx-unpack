# sqx-unpack

Open-source extractor for SQX archives (Squeez / SpeedCommander) on Linux — work in progress.

Status: `sqx l`, `sqx t` and `sqx x` work for method 6 (PPMd-I with custom range coder); other methods are not supported yet.
Format notes: [docs/SQX-format.md](docs/SQX-format.md). License: GPL-3.0-or-later.
